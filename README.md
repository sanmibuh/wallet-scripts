# wallet-scripts

Shell scripts for automating [Wallet by BudgetBakers](https://web.budgetbakers.com/) via its REST API.

Perfect for scheduling automatic backups with crontab and receiving Telegram notifications.

## Quick Start

### 1. Run the Setup Script

```bash
./setup.sh
```

The setup script will:

- Guide you through entering all required settings
- Validate mandatory parameters (API Token, Base URL)
- Optionally configure Telegram notifications
- Create the configuration file automatically
- Make all scripts executable

To reconfigure later, simply run `./setup.sh` again.

### 2. Test Manually

```bash
# Show help and available options
./bin/backup

# Recent backup — previous month + current month (recommended)
./bin/backup recent

# Monthly backup — previous calendar month (default)
./bin/backup monthly

# Monthly backup — specific month
./bin/backup monthly 2026-06

# Yearly backup — previous calendar year (default)
./bin/backup yearly

# Yearly backup — specific year
./bin/backup yearly 2025
```

### 3. Automate with Crontab

```bash
crontab -e

# Recent backup every night at 2 AM (previous month + current month)
0 2 * * * /path/to/wallet-scripts/bin/backup recent >> /tmp/wallet-backup.log 2>&1

# Yearly backup on January 1st at 4 AM (full previous year, permanent file)
# Also cleans up monthly backups already covered by the yearly
0 4 1 1 * /path/to/wallet-scripts/bin/backup yearly >> /tmp/wallet-backup.log 2>&1
```

That's it!

## Automation with Crontab

**This is the main use case for these scripts.** Two complementary backup jobs build a complete, self-cleaning history.

### Backup Strategy

| Mode | Command | Frequency | Content | File |
|------|---------|-----------|---------|------|
| `recent` | `bin/backup recent` | Every night | Previous month + current month | Two `backups/monthly/` files (permanent) |
| `monthly` | `bin/backup monthly` | On demand | Full calendar month | `backups/monthly/wallet-monthly-YYYY-MM.json` (permanent) |
| `yearly` | `bin/backup yearly` | Jan 1st each year | Full previous calendar year | `backups/yearly/wallet-yearly-YYYY.json` (permanent) |

**Why two months nightly?**
Running both the previous and current month ensures any late-arriving bank transactions or edits touching last month are always captured, without the complexity of a sliding daily window.

**Automatic cleanup:**
- `yearly` deletes monthly backups whose month falls within that year (already covered)

### Recommended Crontab

```bash
# Edit your crontab
crontab -e

# Recent backup — every night at 2 AM
# Covers previous month + current month. Both files are overwritten each run.
0 2 * * * /path/to/wallet-scripts/bin/backup recent >> /tmp/wallet-backup.log 2>&1

# Yearly backup — January 1st at 4 AM
# Full previous calendar year. Also removes monthly backups now covered by this yearly.
0 4 1 1 * /path/to/wallet-scripts/bin/backup yearly >> /tmp/wallet-backup.log 2>&1
```

**Important:** Always use absolute paths in crontab.

```bash
# Good
0 2 * * * /home/user/wallet-scripts/bin/backup recent

# Bad
0 2 * * * ~/wallet-scripts/bin/backup recent
```

### Backup File Structure

```
backups/
├── monthly/
│   ├── wallet-monthly-2026-07.json       ← permanent (until yearly covers it)
│   └── wallet-monthly-2026-08.json       ← permanent
└── yearly/
    └── wallet-yearly-2025.json           ← permanent
```

### Alternative: Crontab UI with Docker

For easier management of cron jobs through a web interface, you can use [crontab-ui](https://github.com/alseambusher/crontab-ui) with Docker Compose.

Create a `docker-compose.yml` file in your preferred location:

```yaml
services:
  crontab-ui:
    image: alseambusher/crontab-ui:latest
    container_name: crontab-ui
    restart: unless-stopped
    environment:
      - TZ=Europe/Madrid           # Set your timezone
      - BASIC_AUTH_USER=           # Set your username for web interface
      - BASIC_AUTH_PWD=            # Set your password for web interface
    ports:
      - "8000:8000"
    volumes:
      - /path/to/wallet-scripts:/scripts/wallet  # Mount your wallet-scripts directory
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 10s
```

- **TZ**: Set your timezone (e.g., `Europe/Madrid`, `America/New_York`)
- **BASIC_AUTH_USER**: Username for web interface authentication
- **BASIC_AUTH_PWD**: Password for web interface authentication
- **volumes**: Mount the wallet-scripts directory to `/scripts/wallet` in the container

```bash
# Start the container
docker compose up -d

# Check the logs
docker compose logs -f

# Stop the container
docker compose down
```

**Note:** On older setups, you may need to use `docker-compose` instead of `docker compose`.

Open your browser and navigate to: `http://localhost:8000`

In the web interface, add the cron jobs:

| Name | Expression | Command |
|------|-----------|---------|
| Recent wallet backup | `0 2 * * *` | `/scripts/wallet/bin/backup recent` |
| Yearly wallet backup | `0 4 1 1 *` | `/scripts/wallet/bin/backup yearly` |

## Telegram Notifications (Optional)

To receive notifications about backup events via Telegram, you need to create a Telegram bot and obtain the necessary credentials.

### 1. Create a Telegram Bot

1. Open Telegram and search for **@BotFather** (the official bot for creating bots)
2. Start a chat with BotFather and send the command: `/newbot`
3. Follow the prompts:
   - Choose a name for your bot (e.g., "My Wallet Bot")
   - Choose a username for your bot (must end in `bot`, e.g., `my_wallet_bot`)
4. BotFather will respond with your **Bot Token**
   - It looks like: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`
   - **Save this token** — you'll need it for configuration

### 2. Find Your Chat ID

**Method 1: Using userinfobot**

1. Search for **@userinfobot** in Telegram
2. Start a chat and send any message
3. The bot will reply with your user information, including your **Chat ID**

**Method 2: Using your bot and the Telegram API**

1. Send a message to your newly created bot (any message works)
2. Open this URL in your browser (replace `YOUR_BOT_TOKEN` with your actual token):

   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```

3. Look for the `"chat":{"id":` field in the JSON response

### 3. Configure in wallet-scripts

Once you have your Bot Token and Chat ID:

1. Run the setup script: `./setup.sh`
2. When prompted for Telegram configuration:
   - Enter your **Bot Token** when asked
   - Enter your **Chat ID** when asked

Alternatively, add them manually to `config/wallet.conf`:

```bash
TELEGRAM_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
CHAT_ID="123456789"
```

### 4. Test Your Configuration

```bash
./bin/backup recent
```

You should receive a notification in your Telegram chat.

**Note:** Telegram notifications are optional. If not configured, the scripts will work normally without sending notifications.

## Configuration Reference

Configuration is stored in `config/wallet.conf` (automatically created by `./setup.sh`).

| Variable         | Required | Default                                        | Description                            |
| ---------------- | -------- | ---------------------------------------------- | -------------------------------------- |
| `API_TOKEN`      | Yes      | -                                              | Wallet API token                       |
| `BASE_URL`       | Yes      | `https://rest.budgetbakers.com/wallet/v1/api`  | Wallet API base URL                    |
| `TELEGRAM_TOKEN` | No       | -                                              | Telegram bot token (for notifications) |
| `CHAT_ID`        | No       | -                                              | Telegram chat ID (for notifications)   |

Example `config/wallet.conf`:

```bash
API_TOKEN="your-api-token-here"
BASE_URL="https://rest.budgetbakers.com/wallet/v1/api"
TELEGRAM_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
CHAT_ID="123456789"
```

## Troubleshooting

### "Configuration file not found"

Run the setup script to create the configuration file:

```bash
./setup.sh
```

### Scripts not executable

```bash
chmod +x bin/*
chmod +x setup.sh
```

### Telegram notifications not working

**Possible causes:**
- Incorrect bot token
- Incorrect chat ID
- Bot hasn't been started (send `/start` to the bot first)

Test with a direct curl command:

```bash
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/sendMessage" \
     -d "chat_id=<YOUR_CHAT_ID>" \
     -d "text=Test message"
```

### Cron job not running

1. Always use absolute paths in crontab
2. Add logging to debug:

   ```bash
   0 2 * * * /path/to/wallet-scripts/bin/backup recent >> /tmp/wallet.log 2>&1
   ```

3. Check cron logs:

   ```bash
   # macOS
   log show --predicate 'process == "cron"' --last 1h

   # Linux
   grep CRON /var/log/syslog
   ```

## Tips

### Test Before Automating

Always run scripts manually first to verify behavior before adding to crontab:

```bash
./bin/backup recent
./bin/backup yearly
```

### Initial Full History Backup

Before setting up the cron schedule, back up your full history manually:

```bash
# Back up each past year individually
bin/backup yearly 2023
bin/backup yearly 2024
bin/backup yearly 2025

# Then let the cron schedule take over
```

### Backup Your Configuration

```bash
cp config/wallet.conf config/wallet.conf.backup
```

### Use Logging for Cron

Always redirect output to a log file when running from crontab:

```bash
0 2    * * *   /path/to/wallet-scripts/bin/backup recent  >> /tmp/wallet-backup.log 2>&1
0 4    1 1 *   /path/to/wallet-scripts/bin/backup yearly  >> /tmp/wallet-backup.log 2>&1
```
